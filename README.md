# NEXT - Votre Bibliothèque de Jeux

NEXT est un gestionnaire de bibliothèque personnel, sécurisé et social, conçu pour centraliser votre expérience de jeu au sein d'une interface unique.

---

## Pourquoi NEXT ?

L'objectif de NEXT est de proposer une alternative légère et extensible pour organiser ses titres et interagir avec son réseau de manière indépendante.

### Fonctionnalités Clés

*   Gestion Centralisée : Regroupez vos jeux locaux dans une interface fluide et réactive.
*   Social P2P : Système de messagerie instantanée en pair-à-pair pour communiquer sur le réseau sans serveur central.
*   Sécurité AES-256 : Chiffrement de la base de données locale pour protéger vos informations personnelles.
*   Système de Plugins : Architecture modulaire permettant l'ajout de fonctionnalités personnalisées via des scripts JavaScript.
*   Expérience Cinématique : Interface immersive avec séquence d'introduction et animations de transition.

---

## Installation

1. Téléchargez la version stable dans l'onglet Releases.
2. Exécutez l'installateur pour déployer le client.
3. Configurez votre profil local pour commencer l'organisation de votre bibliothèque.

---


## Stack Technique

*   **Framework** : Electron
*   **Communication** : UDP (P2P Chat) & Axios (GitHub Updates)
*   **Compression** : Support natif 7-Zip
*   **Style** : CSS3 pur avec variables dynamiques (Thèmes OLED & Darker)
